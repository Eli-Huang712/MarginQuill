把这张纸稿逐字转录为可编辑 Markdown，另用 issues 数组记下需要核对的地方。保留原文顺序、措辞、标题、段落、列表、缩写和符号。被强调的手画下划线用 <u>文字</u> 包住实际范围。每个框图用 mermaid 代码块，使用 flowchart、安全的简单 ID 和双引号标签，保留原图可以确认的节点、分支和箭头。避免推断看不清的字或连线。两个节点确定相连但方向不明时，用无箭头实线。
markdown 只包含确认的正文和图，识别错误提示、待核对标记、置信度、附注式解释全部留在 issues。字句无法确定时留出空缺而非补写。下划线范围不明确时保留原文文字，把范围写到 issues。看不清的箭头端点不要录入图，单独记到 issues。每条 issue 用简短的 category（例如 字词、下划线、箭头）、location（页面上的位置或相邻内容）、detail（看见什么、需要核对什么）。无疑点时返回空数组。
每条疑点还要给出 anchor 和 box。anchor 是 markdown 里已经转录、紧挨疑点的短词句，原样引用纯文字，优先选在本页唯一出现的 4–24 个字；框图疑点可以引用可辨认的节点标签。找不到可靠的相邻文字时用 null。box 表示疑点在给定图片里的大致矩形范围，左上为原点，x、y、width、height 都使用 0 到 1 的图像比例。只框住相关字词、标记或箭头；如果只能判断在哪一页，box 用 null。
